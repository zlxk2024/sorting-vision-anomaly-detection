# 快递分拣视觉数据标注标准

- 标准版本：`v1.7`
- 生效日期：`2026-07-26`
- 适用数据：`sorting_yolo_stage1`
- 标注格式：YOLO Detection
- 标准状态：正式执行版

## 1. 类别定义

| 类别 ID | 类别名 | 中文含义 | 可视化颜色 |
|---:|---|---|---|
| 0 | `parcel` | 包裹 | 蓝色 |
| 1 | `drawer_open` | 打开的抽屉门板 | 绿色 |
| 2 | `drawer_closed` | 关闭的抽屉门板 | 白色 |
| 3 | `chute` | 一个完整格口对应的落件通道 | 红色 |
| 4 | `bag` | 集包袋 | 黄色 |

类别 ID 与名称一经用于训练不得交换。修改类别定义时必须升级标准版本。

## 2. 通用画框规则

1. 逐张查看原图后再标注，禁止用固定坐标、整批复制坐标或仅凭相邻帧插值生成最终标签。
2. 只标清晰可辨认的真实目标；不确定时不猜、不标，记录为待复核。
3. 框应贴合目标最外侧可见边界，并完整包含目标实体。
4. 框外允许保留约 2～5 像素安全边距，不能裁掉目标，也不能包含大面积无关背景。
5. 画面边缘仅露出一小部分、无法确定完整实体边界的目标不标。
6. 严重运动模糊、遮挡严重或类别无法判断的目标不标。
7. 不把设备结构、阴影、反光、导轨、立柱、显示屏、空白区域误标为目标。
8. 同一目标只能使用一个类别，禁止重叠标成两个互斥类别。
9. YOLO 标签必须基于无框、无文字、无播放器控件的原始图片生成。
10. 每一帧必须从左到右重新清点该类的全部实例，不能因为已经跟踪到一个目标就停止查找同类目标。
11. 坐标公式、固定框、复制上一帧和线性插值只能用于产生候选框，不能作为最终标注；最终每个框都必须在该帧原图上单独确认边界。

## 3. 各类别的边界标准

### 3.1 `parcel`

标注对象：纸箱、塑料袋装快递、软包、文件袋等可辨认的完整包裹实体。

画框要求：

- 完整包住包裹所有可见部分，包括软袋凸出的边角。
- 包裹被立柱少量遮挡时，按其可推断的完整外轮廓画框；遮挡过半且无法判断边界时不标。
- 运动中的包裹若轮廓仍可辨认，可以标注，框住全部运动模糊区域。

禁止标注：

- 白色导流板、银色金属板、橙色门板、黄色设备部件。
- 阴影、反光、空抽屉、空格口。
- 只有疑似包裹颜色但没有明确实体轮廓的区域。

### 3.2 `drawer_open`

判定原则：门打开以后，门板呈平放或近似水平状态。

标注对象：打开后处于水平位置的实际门板本体。

画框要求：

- 只框水平门板的实体边界。
- 在当前机位中，它通常表现为靠近橙色轨道上方的一块横向、扁平门板。
- 门板上有包裹时，门板和包裹分别标注，两个框可以重叠。

新机位校准规则（v1.6）：

- 在 `两个口的视频.mp4` 的高位俯拍机位中，实际已经向外翻开的银色门板会同时露出较宽的门板实体和前侧面，二维图像中可能呈横向矩形。
- 当银色门板位于白色斜纹承载面下方、已经向前/向外展开，形成包裹离开承载面的打开通道时，标注为 `drawer_open`。
- 不得仅因为该银色门板在二维图像中有明显高度、看起来像竖直矩形，就标成 `drawer_closed`。
- 本规则的人工校准基准为新视频约 61.80 秒用户红框门板。

新机位开关对照规则（v1.7）：

- `drawer_closed`：门板收回时只露出贴近承载面下沿的窄、薄挡边，可见面积较小，整体与抽屉下沿基本齐平。
- `drawer_open`：门板翻开以后露出大面积银色板面，门板明显向下/向外展开，可见高度和面积明显大于关闭挡边。
- 同一画面可能同时出现打开和关闭门板，必须逐个判断，不能把所有银色下沿统一标成同一类别。
- 蓝框人工基准为 `drawer_closed`，红框人工基准为 `drawer_open`。
- 颜色只用于用户示意，不是模型类别依据；实际标注依据是门板暴露面积、厚薄、位置以及与承载面的机械关系。

禁止标注：

- 白色斜坡、导流板、轨道、横梁、设备底座。
- 门板后方或下方的机械结构。
- 画面边缘不完整、无法确认整个门板的对象。
- 仅因为某处是水平结构就推断为打开门板。

### 3.3 `drawer_closed`

判定原则：门关闭时，门板呈竖直或近似竖直状态。

多机位透视补充规则：

- “竖直或近似竖直”指门板相对于设备的真实姿态，不是标注框在二维图像中的宽高比。
- 在高位俯拍机位中，竖立的关闭门板可能被透视压缩成横向扁长区域；只要根据门板的安装位置、前侧实体边缘及其与承载面的关系能够确认其仍处于关闭位置，必须标注为 `drawer_closed`。
- 不得因为关闭门板在画面里看起来较扁、较横，就改标为 `drawer_open`。
- `drawer_open` 仍只标实际翻转到打开位置、形成可落件水平面的门板；同一机位中应结合前后帧的机械姿态变化确认。

标注对象：抽屉前端处于关闭状态的门板下沿/关闭挡边。整辆抽屉或承载体仅用于确认该下沿的归属，不作为 `drawer_closed` 框的范围。

画框要求：

- 只框抽屉最前端实际起关闭作用的下沿/挡边，框线贴合该关闭实体的可见外边缘。
- 必须先确认整辆抽屉的左右边界，再在该抽屉前端定位与其对应的关闭下沿，避免把框错配到左侧或右侧相邻抽屉。
- 框完整包含关闭下沿本体，但不向上扩展到大面积银色斜纹承载面，也不向下包含驱动机构或橙色固定导轨。
- 不把门板两侧机械装置、底座或后方空白包含进来。

禁止标注：

- 翻转机构背面、金属支架、驱动组件或模糊机械部件。
- 白色斜坡、导流板、橙色横梁。
- 画面边缘只显示一部分的门板。
- 不能确认是门板正面的对象。

完整性判断：

- 关闭下沿的左右实体边缘均可辨认，并能与相邻抽屉及机械结构分开时，属于完整 `drawer_closed`，必须标注。
- 关闭下沿在画面内完整出现，即使靠近边缘，也不能因为“看起来接近边缘”而漏标。
- 只有关闭下沿被图像边界真正裁断、看不到其中一侧实体边缘时，才按不完整目标跳过。
- 一个画面出现两块或更多关闭下沿时，每块都要分别标注，不能只标最显眼或位于中间的一块。

### 3.4 `chute`

标注对象：一个完整格口所对应的橙色落件通道。

一个格口标一个 `chute`，画框边界按以下规则统一：

- 左右边界：该格口两侧的分隔板或结构边界。
- 上边界：包裹进入该格口橙色落件通道的位置。
- 下边界：该格口橙色通道主体的结束位置。
- 框住属于该格口的完整橙色落件通道，不跨到相邻格口。

禁止标注：

- 把整台橙色设备外壳标成一个 `chute`。
- 一个框同时覆盖两个或多个格口。
- 只框任意一小块橙色表面。
- 把显示屏、立柱、抽屉、包裹或集包袋算入通道实体。
- 通道主体和格口归属均无法确定的边缘残片。

边缘补充规则（v1.1）：

- 如果格口侧板贴近或接触画面边缘，但橙色通道主体、另一侧边界以及该通道所属格口仍能可靠确定，必须标注。
- 此时边缘侧框线落在图像边界上，框住当前画面内全部可见的通道主体。
- 不能因为侧板只显示一部分就漏标整个清晰可辨的 `chute`。

### 3.5 `bag`

标注对象：用于接收包裹的集包袋本体。

画框要求：

- 框住袋口、袋身以及当前画面内全部可见的袋体。
- 如果袋底超出画面，仍可标注，但框应延伸到图像边缘，并完整包含所有可见袋体。
- 不把袋子周围的大面积输送带、地面或相邻袋子包含进来。

禁止标注：

- 仅框袋口，不包含可见袋身。
- 把输送带、支架或周围背景当作袋体。
- 画面边缘仅露出少量布料、不能确认是一个独立集包袋的对象。

## 4. 遮挡、截断与模糊处理

| 情况 | 是否标注 |
|---|---|
| 目标完整、轮廓清楚 | 标注 |
| 少量遮挡，仍能确定目标边界 | 标注 |
| 遮挡过半，无法可靠判断边界 | 不标，进入待复核 |
| 目标在画面边缘但主体和边界基本完整 | 标注 |
| 画面边缘只露出局部，实体和归属无法确定 | 不标 |
| `chute` 侧板贴边，但通道主体和格口归属可确定 | 标注当前全部可见通道 |
| 有运动模糊但目标类别与整体范围清楚 | 标注全部模糊实体范围 |
| 模糊到无法确定类别或边界 | 不标，进入待复核 |

## 5. 单张图片标注流程

每张图必须按固定顺序检查：

1. 从左到右查找并标注全部明确的 `parcel`，记录本帧数量。
2. 从左到右查找全部水平门板，标注 `drawer_open`，记录本帧数量。
3. 从左到右查找全部竖直橙色/棕色门板，标注 `drawer_closed`，记录本帧数量。
4. 从左到右按格口逐一检查并标注 `chute`，记录本帧数量。
5. 从左到右查找并标注完整可见的 `bag`，记录本帧数量。
6. 逐框复查：类别是否正确、目标是否完整、是否包含过多背景。
7. 全图复查：是否漏标清晰目标，是否误标设备结构。

即使某一类在图片中不存在，也必须完成该类检查；不存在时保持零标注。

## 6. 时序首尾帧与连续性检查

视频连续帧标注完成后，必须再进行一次时序检查：

1. 按帧号顺序对每一类分别统计实例数量。
2. 若同一目标在前后帧均有标注，但中间某帧突然消失，必须回看中间帧，不能直接接受断点。
3. 目标进入画面时，逐帧确定“首次完整可见帧”；该帧必须开始标注，不能人为延后若干帧。
4. 目标离开画面时，逐帧确定“最后完整可辨帧”；之后才停止标注。
5. 对 `drawer_closed`，重点检查画面左右两侧是否有第二块或新增门板进入。
6. 对 `parcel`，重点检查同一帧是否存在两个或更多独立包裹。
7. 每个目标的首个正帧、最后正帧及其相邻帧必须局部放大复核。
8. 最终标注不得仅由运动轨迹公式或前后帧插值得出。

## 7. 质量验收规则

单张图片满足以下条件才算通过：

- 没有把背景或机械结构误标为包裹。
- 包裹框完整包含实体。
- `drawer_open` 只对应水平门板。
- `drawer_closed` 只对应竖直门板。
- 每帧所有完整可见的竖直门板均已标注，不能只标其中一块。
- 不标画面边缘不完整的抽屉门板。
- `chute` 按一个完整格口一个框进行标注。
- `bag` 包含完整可见袋体。
- 无明显漏标、错类和严重松框/紧框。

批次质量要求：

- 每批先标 10 张，逐张输出可视化图片审核。
- 10 张全部确认后才可扩大批次。
- 扩大批次后仍需逐张视觉确认，不使用拼图代替单图检查。
- 每 100 张至少进行一次全量复核；发现系统性错误时整批退回。
- 未通过审核的数据不得进入训练集、验证集或测试集。
- 连续帧的类别数量和目标轨迹已完成断点检查。

## 8. 标准版本与反馈机制

1. 所有标注批次的 `README.md` 必须记录使用的标准版本，例如 `annotation_standard: v1.0`。
2. 用户反馈先修改本标准并升级版本，再按新标准修改标签。
3. 禁止在不修改版本号的情况下悄悄改变类别定义或画框边界。
4. 旧标准生成的标签不得与新标准标签混用，除非完成迁移复核。
5. 有争议的图片放入 `needs_review/`，不得由标注者自行猜测。

## 10. YOLO 标签格式

每个目标一行：

```text
class_id x_center y_center width height
```

坐标均按图片宽高归一化到 `0～1`。类别顺序必须与第 1 节一致。
