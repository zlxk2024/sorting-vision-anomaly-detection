# 数据集说明

## 用途

本项目数据用于快递分拣视觉模型训练、检测能力评估和异常事件规则验证。

核心目标类别：

1. `parcel`：包裹；
2. `drawer_open`：打开并平放的抽屉门板；
3. `drawer_closed`：抽屉前端关闭下沿；
4. `chute`：完整落件闸口通道；
5. `bag`：集包袋。

异常事件包括开门不掉件、飘格/掉错格口、一车两件以及失速/滞留。

## 标注规范

正式规范见：

`datasets/sorting_yolo_stage1/ANNOTATION_STANDARD_v1.md`

训练前必须维持类别 ID 顺序，不得交换类别名称和编号。

## 数据目录

- `datasets/sorting_yolo_stage1/`：第一阶段训练及标注数据；
- `datasets/sorting_two_chutes_supplement/`：新机位补充数据；
- `runs/`：模型训练、推理和事件识别结果；
- `reports/`：评估报告及演示材料。

## 数据质量状态

数据同时包含正式复核样本、首轮预标注样本和实验输出。训练时应优先使用
清单中状态为人工确认或视觉复核通过的数据，不应直接把所有实验目录混合训练。
