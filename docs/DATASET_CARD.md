# 数据集说明（源码发布版）

本次 GitHub 版本仅包含代码、技术文档和模型，不包含业务视频、图片、标签、报价与运行结果。

V2 历史训练使用 1,081 张旧/新场景图片，其中 train/val/test 为 754/162/165 张。新场景按十秒时间块划分，旧场景按秒划分；旧场景仍有视频近邻帧相关性风险。

类别固定为 0 parcel、1 drawer_open、2 drawer_closed、3 chute、4 bag。标注规范见 ANNOTATION_STANDARD_v1.md。只有已复核数据可用于正式训练；模型预标注不等于人工确认。

部署者可使用自己的视频直接调用推理服务，无需训练数据。重新训练时需自行取得数据授权，准备脚本要求的目录和 V1 初始化权重；历史报告中的数据路径是研发记录，不表示这些数据包含在仓库中。
