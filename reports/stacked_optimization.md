# 堆叠快递第一轮算法优化

## 改动

1. 在5毫米高度图上保留每个栅格的最高点。
2. 相邻栅格高度差超过12毫米时切断连通关系，用于识别上下层台阶。
3. 过滤吸取评分低于0.75的狭窄碎片。
4. 根据候选俯视包围框重叠和表面高度建立遮挡关系。
5. 只把没有更高表面阻挡的候选加入当前抓取队列，抓取后要求重新拍照。
6. 增加RGB-D接口，可将任意实例分割模型输出的二维掩码映射到深度点云。

## 验证结果

| 场景 | 旧算法 | 新算法 |
| --- | ---: | ---: |
| 单层10件 | 10 | 10 |
| 三层堆叠10件 | 1个整体 | 10个可见表面候选 |
| 堆叠场景当前可抓候选 | 未判断 | 2 |
| 首选抓取目标 | 未判断 | `pkg_0008` |
| 100帧单层压力测试 | 388/388 | 388/388 |

## 重要边界

- 新算法输出的是可见表面候选，不能证明已经恢复10个完整快递实例。
- 堆叠场景的候选吸取点相对完整物体中心平均偏差约97.7毫米，底层外接框可能跨越被遮挡区域。
- 当前抓取队列只允许2个顶层候选，其余候选必须等待上层快递移除后重新拍照。
- 同高度、紧贴且表面连续的快递仍需要RGB实例分割；完全不可见的快递只能在上层移除后识别。

## 第二轮优化

### 实例掩码安全修正

实例掩码中的大型空洞可能是上层快递造成的遮挡，不能像普通深度缺点一样整体填充。RGB-D接口现在只闭合小裂缝，保留大型遮挡孔，避免把吸取点选在不可见区域。

使用真实实例标签模拟理想UOAIS输出后：

| 指标 | 结果 |
| --- | ---: |
| 检出实例 | 10/10 |
| 吸取点到本实例可见表面平均距离 | 3.73 mm |
| 可见表面距离P95 | 5.02 mm |
| 吸取点到完整物体顶部中心平均距离 | 99.79 mm |

这说明实例掩码能够保证吸取点属于正确的可见表面，但不能恢复被遮挡物体的真实中心。

### 抓取后重拍闭环

每轮重新渲染相机深度、重新分割和重新计算遮挡关系，选择一个顶层候选后将其移除：

| 指标 | 结果 |
| --- | ---: |
| 初始快递数 | 10 |
| 清空快递数 | 10 |
| 抓取/重拍轮数 | 10 |
| 推荐点到真实可见表面平均距离 | 6.54 mm |
| 可见表面距离P95 | 15.66 mm |
| 最大距离 | 19.25 mm |

闭环仿真成功清空场景。该结果仍基于合成深度和已知物理布局，现场还需要验证吸盘密封、机械臂碰撞、快递移动及相机重新曝光时间。
